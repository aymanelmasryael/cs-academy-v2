# Changelog

## [0.1.0] — 2026-07-16

### Added

- Initial release.
- 10,000 CS problem-solving Q&A cards with pagination (50 per page).
- Keyword search, difficulty/type filters, bookmarking, and deep linking.
- Dark-mode glassmorphism UI, zero external dependencies (except Google Fonts).
- Static web app — open `index.html` in any browser to use.

### Notes

- The entire 10,000-record dataset is synthetically generated as a structural scaffold.
- All answers, explanations, and code examples are placeholder text.
- The 16 MB data file is unminified for readability; a production build should minify.
- This is a pre-release version. Data quality and payload size improvements are planned.
